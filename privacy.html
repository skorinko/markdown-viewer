Privacy Policy

Effective 27 October 2026

In short: Markdown Viewer does not collect, store, share or sell any personal data. Everything it does happens on your Mac.

Who we are

Markdown Viewer for Safari is published by Elena Trifonova, an individual developer, through the Mac App Store.

What the extension accesses

Markdown Viewer runs in Safari only on pages whose address ends in .md, .markdown, .mdown or .mkd. On those pages it reads the Markdown text that Safari has already loaded and replaces it with a formatted version. It does not read or change any other page.

Network requests

Markdown Viewer makes no requests to the developer or to any third party. It contains no analytics, advertising, tracking or crash-reporting code. In two cases it requests the page you are already viewing again, from the same address:

  • When the server does not state a text encoding, so the file can be read correctly as UTF-8.
  • For live reload, only on local addresses such as localhost and 127.0.0.1, to notice when the file changes on your own computer.

Images and links inside a Markdown file load from wherever the file points, exactly as they would on any web page.

What is stored

The extension keeps two settings in Safari's extension storage on your Mac: whether rendering is turned on, and whether the contents sidebar was left open. They never leave your device.

Purchases

Markdown Viewer is sold through the Mac App Store. Apple handles payment, and the developer does not receive your name, email address or payment details. Apple's own privacy policy applies to the purchase.

Children

Markdown Viewer collects no data from anyone, including children.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
