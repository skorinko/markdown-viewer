Support

Help with turning on and using Markdown Viewer for Safari.

Turn it on

  1. Open the Markdown Viewer app once.
  2. In Safari, open Settings, then Extensions, and tick Markdown Viewer.
  3. Click Edit Websites and set Markdown Viewer to Allow on every website.

Then open a Markdown file to try it, for example Mermaid's README.

Using it

  • Raw (top right) or ⌥R switches between formatted and original text.
  • Contents opens the outline of headings.
  • Click a diagram to open it full screen. Pinch or ⌘-scroll to zoom, drag to move, Esc to close.
  • Hover a code block and click the copy icon to copy it.
  • The Markdown Viewer button in the Safari toolbar turns rendering on or off.

Common questions

A .md page still shows raw text. Check that the extension is allowed on that website. Click the Markdown Viewer button in the Safari toolbar, or open Settings, Extensions, Edit Websites.

Can I hide the toolbar button? Yes. In Safari, choose View, then Customize Toolbar, and drag the Markdown Viewer button off the toolbar. Markdown Viewer keeps working without it. Safari adds a button for every extension, so the extension can't remove it on its own.

A GitHub page doesn't change. GitHub's own file view is already an HTML page. Click Raw on GitHub to open the Markdown file itself.

Safari downloads the file instead of showing it. The server is sending the file as a download, and Safari does this before any extension can act. Ask the site owner to serve Markdown as text/plain or text/markdown.

Local files (file://) don't render. Safari does not run extensions on local files. Serve the folder instead, for example with python3 -m http.server, and open http://localhost:8000/your-file.md. You get live reload that way too.

A diagram shows an error. The Mermaid code in the file has a mistake. The message under the diagram names the line, and the source is shown below it.

Contact

Email extensions.support@icloud.com. Please include your macOS and Safari versions and, if you can, a link to the file that misbehaves.
